# Chiikawa Pet Installer

This skills-only plugin installs the bundled animated Chiikawa sprite sheet into an eligible user's ChatGPT Pets library and selects it.

After installing the plugin, ask:

> 번들된 치이카와 펫을 설치하고 선택해줘.

The official ChatGPT Pets feature must be available to the recipient. Each installation creates a separate user-owned custom pet; the package contains no account ID, upload session, private link, or credential.
